# Coord Buffer

Fullstack implementation of [Coord Buffer Cli](https://github.com/druwan/coord-buffer-cli). [Fast-API Fullstack template](https://github.com/fastapi/full-stack-fastapi-template/tree/0.10.0) used.

Visualizes all TMA's from eAIP Sweden: ![Polygons](./frontend/assets/images/Coord_Buffer_Map.png "Polygons example")

An user can then select any of the TMA's and apply a buffer (in Nm). ![Users buffered polygons](./frontend/assets/images/Coord_Buffer_Polygons.png)

The buffered polygon is then added to the map: ![Buffered Polygon Example](./frontend/assets/images/Coord_Buffer_Map_Example.png "Buffered polygon example")
